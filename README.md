# 희망가정폭력상담소 관리 시스템 (Hope DV Counseling Management System)

가정폭력 피해자 전문 상담 현장의 업무 프로세스를 디지털화하여, 신속한 위기 개입과 체계적인 사례 관리 및 상담소 인력 운영을 지원하는 올인원 웹 관리 시스템입니다.

---

## 🚀 빠른 시작 (실행 방법)

### 1. 원클릭 실행 (Windows)
프로젝트 폴더의 `run.bat` 파일을 더블클릭하면 자동으로 웹 서버가 실행됩니다.

### 2. 명령줄(CLI) 실행
```bash
python run.py
```
서버 기동 후 브라우저에서 다음 주소로 접속합니다:
👉 **`http://127.0.0.1:8000`**

---

## 🌟 5대 핵심 기능 안내

### 1. 📞 전화 상담기록 화면 (`/calls`)
- **실시간 위험도 분류 (Triage)**:
  - **긴급위험(HIGH)**: 흉기 위협, 살해 협박, 심각한 신체 상해, 즉각 분리 및 피난 필요 건 (붉은색 강조)
  - **주의(MEDIUM)**: 반복적 신체/언어 폭력, 심리적 불안정
  - **일반(LOW)**: 갈등 상담, 법률 및 지원 제도 안내
- **비밀보장 & 익명 접수 지원**: 가명 또는 익명 처리 토글 옵션
- **가정폭력 특화 분류 체계**:
  - 폭력 유형: 신체적, 정서/언어적, 경제적, 성적, 통제/방임/스토킹
  - 가해자 관계: 배우자(법률혼), 사실혼, 전배우자, 교제상대(데이트폭력), 직계가족 등
  - 긴급 조치 연계: 긴급피난/단기쉼터 연계, 경찰(APO) 동행/신변보호, 무료 법률구조, 응급의료지원
- **데이터 관리**: 상담 상세 열람, 수정/삭제, 검색 및 필터링, **CSV 엑셀 다운로드**

### 2. 🏖️ 휴가 신청 및 결재 관리 (`/leaves`)
- **연차 현황 한눈에 보기**: 총 부여 연차, 사용 연차, 잔여 연차 실시간 표시
- **다양한 휴가 유형**: 연차(종일), 오전반차(0.5일), 오후반차(0.5일), 병가, 경조사, 대체휴가, 공가
- **업무 대행자 지정**: 긴급 위기 상황 대비 부재 시 상담 대행 상담사 지정
- **원클릭 결재 워크플로우**: 관리자(소장/선임) 권한 시 원클릭 승인(잔여연차 자동 차감) 및 사유 입력 반려 처리

### 3. 👥 상담사 관리 화면 (`/counselors`)
- **상담소 인력 종합 명부**: 직급(소장, 팀장, 선임상담사, 상담사), 권한 등급(DIRECTOR, SENIOR, COUNSELOR, INTERN)
- **전문 분야 프로파일**: 위기개입, 부부갈등, 청년/교제폭력, 트라우마치유 등 상담사별 강점 분야 관리
- **업무 배정 모니터링**: 상담사별 현재 배정된 누적 상담 건수 및 대기 업무 확인
- **계정 전환기능**: 상단 헤더의 셀렉터로 언제든지 다른 상담사 계정으로 즉시 전환하여 역할별 화면 체험 가능

### 4. 📝 일일 업무일지 (`/worklogs`)
- **당일 상담 실적 자동 연동**: 별도 계산 없이 당일 접수된 전화상담 건수 및 고위험 긴급 건수가 일지에 자동 연동
- **체계적인 4대 영역 기록**:
  1. 상담 및 내담자 지원 업무 내역
  2. 센터 일반 행정 및 대외 협력 (경찰, 쉼터, 지자체)
  3. 위기 개입 및 특이사항 (긴급 피난, 신변보호 신청 등)
  4. 익일 계획 및 인수인계
- **센터장 검토/피드백**: 관리자 검토 의견 등록 및 결재 완료 마크
- **출력(인쇄) 최적화**: 브라우저 인쇄 버튼 클릭 시 불필요한 UI가 제외된 정돈된 A4 보고서 형식 출력

### 5. 👤 마이페이지 (`/mypage`)
- **상담사 개인 전용 대시보드**: 내 배정 상담 건수, 조치 완료 건수, 작성 일지 수, 잔여 연차 요약
- **개인 정보 수정**: 연락처, 이메일, 전문 상담 분야, 비밀번호 변경
- **내 담당 상담 및 휴가 내역 모아보기**: 내가 맡은 상담 기록과 내가 낸 휴가 신청 현황 즉시 조회

## 🤖 Typebot 챗봇 연동 가이드

상담소 웹페이지에 **Typebot(안심 상담 챗봇)**을 연동하여 24시간 비대면 피해 상담 접수를 진행할 수 있습니다.

### 1. 화면 우측 하단 챗봇 버블 띄우기
1. 상단 메뉴 우측의 **`[챗봇 연동]`** 버튼을 클릭합니다.
2. [Typebot.io](https://typebot.io)에서 생성한 본인의 봇 Slug(ID)를 입력하고 **[적용]**을 누릅니다.
3. 페이지가 새로고침되며 우측 하단에 따뜻한 안심 상담 챗봇 플로팅 버블이 활성화됩니다.

### 2. 챗봇 상담 내역 자동 DB 저장 (Webhook)
Typebot에서 내담자가 남긴 답변을 우리 관리 시스템의 **1. 전화상담기록**에 자동으로 등록할 수 있습니다:
- **Webhook URL**: `https://your-domain/api/webhook/typebot` (또는 로컬 `http://127.0.0.1:8000/api/webhook/typebot`)
- **Method**: `POST`
- **전송 필드 예시**:
  ```json
  {
    "client_name": "익명내담자",
    "is_anonymous": "익명",
    "client_gender": "여성",
    "client_age_group": "20대",
    "client_phone": "010-0000-0000",
    "client_region": "서울",
    "violence_types": ["신체적 폭력", "정서/언어적 폭력"],
    "perpetrator_relation": "교제상대",
    "risk_level": "HIGH",
    "main_issues": "심야 가정폭력 긴급 대피 및 쉼터 문의",
    "counseling_content": "챗봇 질문에 답변한 상세 내용..."
  }
  ```
- 웹훅이 수신되면 실시간으로 상담 기록에 추가되어 다음 날 출근한 상담사가 즉시 확인하고 조치할 수 있습니다.

## 🛠️ 기술 스택
- **Backend**: Python 3.14, FastAPI, Pydantic, Uvicorn, SQLite
- **Frontend**: HTML5, Tailwind CSS, Lucide Icons, Chart.js, Vanilla JavaScript
- **Database**: `counseling_center.db` (초기 샘플 데이터 8건의 상담 기록, 4명의 상담사, 휴가 및 업무일지 자동 포함)
